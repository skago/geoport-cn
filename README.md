# GeoPort CN · 国内优化版

> 基于 [davesc63/GeoPort](https://github.com/davesc63/GeoPort) 的国内优化版：无需越狱的 iOS 定位模拟工具。
> Your Location, Anywhere!

**面向国内网络环境优化，开箱即用**：默认高德地图底图、依赖安装走国内镜像、外网请求全部后台化不阻塞界面。在原版基础上，GeoPort CN 面向**中文用户 / 国内网络环境**，新增了国内地图源（含坐标纠偏）、历史记录与收藏等功能，并做了一系列安全与稳定性修复。

## ✨ 相对上游的新特性

- 🖱️ **双击即用，全程免密码**：一键安装器 + 应用图标，双击启动自动开浏览器；iOS 17+ 走免 root 的用户态隧道，从启动到停止零密码零终端
- 📡 **Wi-Fi 免线连接**：USB 配对一次后，手机和 Mac 在同一 Wi-Fi 即可用，数据线都不用插
- 🗺️ **地图源可选**：新增高德地图（街道/卫星，默认）、百度地图、Google（街道/卫星），保留原版 15 个国际底图源；瓦片加载失败自动降级，地图永不开天窗
- 📐 **坐标系自动纠偏**：内置 WGS-84 ↔ GCJ-02 ↔ BD-09 转换，高德/百度底图上选点、搜索、路线回放均精确对位（发送给手机的坐标始终是 WGS-84）
- 🕐 **历史记录**：每次成功模拟位置自动记录（50 米内自动去重，上限 100 条），点击即可一键复用
- ⭐ **收藏夹**：常用地点收藏、改名、去重，不用每次重新填坐标
- ⚡ **首页秒开、永不被外网拖累**：地图初始化零网络请求；油价/版本检查/广播全部后台预取 + 缓存，弱网/代理环境从卡 30 秒+ 降到毫秒级
- 🩺 **服务健康自愈**：页面常驻连接状态徽章，服务启动中/断线时自动重连并给出明确指引；页内一键查看服务日志
- 🇨🇳 **全中文界面**：设备连接、模拟定位、错误提示全部中文，常见故障提示自带解决方法
- 🔒 **安全修复**：移除 `verify=False`、关闭 Werkzeug debugger、默认只监听 `127.0.0.1`（`--host` 可开放局域网）、Flask 多线程模式
- 🐍 **现代依赖适配**：适配 pymobiledevice3 v11.6x 新 API（上游源码已落后于打包版）

详细改动列表见 [CHANGES.md](CHANGES.md)。

## 🚀 安装与运行

依赖：Python 3.10+ 和一台 Mac；iPhone/iPad **首次**需用 USB 线连接一次完成配对，之后即可同 Wi-Fi 免线使用。

### 安装（一次搞定）

```bash
git clone https://github.com/skago/geoport-cn.git
cd geoport-cn
open setup.command      # 等同于在 Finder 里双击 setup.command
```

安装器会自动：检查 Python → 装依赖（国内镜像）→ 把「GeoPort CN.app」放进应用程序目录。

### 日常使用（只有一个动作）

**双击「GeoPort CN.app」**（启动台 / Spotlight 搜 "GeoPort"）→ 服务后台启动，
浏览器自动打开——**全程无需密码**（iOS 17+ 走免 root 的用户态隧道）。
再次双击可选择「打开页面」或「停止服务」。

手机连接方式二选一：
- **Wi-Fi（日常推荐）**：与 Mac 同一 Wi-Fi，免数据线；注意手机长时间锁屏会断开，解锁即恢复
- **USB 线**：最稳定；首次连接必须用线（完成配对信任）

### 终端方式（调试用）

```bash
cd geoport-cn
./start               # iOS 17+ 无需 sudo（用户态隧道）
```

然后浏览器打开 `http://localhost:54321`。

<details>
<summary>常用参数</summary>

| 参数 | 说明 |
|---|---|
| `--port` | Web UI 端口（默认 54321，被占用时自动换随机端口） |
| `--host` | 监听地址（默认 127.0.0.1；`0.0.0.0` 开放局域网，注意安全） |
| `--no-browser` | 不自动打开浏览器 |
| `--udid` | 指定目标设备 |
| `--wifihost` | 通过 Wi-Fi 连接指定设备 IP |

</details>

数据文件：历史/收藏在 `~/GeoPort/saved_locations.json`；服务日志在 `~/GeoPort/logs/geoport-cn.log`。

## 🔐 隐私说明

- **所有位置数据只存在你自己的电脑上**（`~/GeoPort/`），无遥测、无账号、无上传
- 启动时会访问 GitHub 检查版本更新（匿名，失败静默不影响使用）
- 刷新设备列表时会做**一次** IP 归属地查询（仅用于油价功能的区域默认值，进程内缓存，之后不再查询；地图初始定位不联网）
- Web 界面只监听本机（127.0.0.1），局域网默认不可访问

## 🔍 关于搜索

搜索开箱即用、无需任何配置：输入地名（如"天安门"）或 `纬度, 经度` 都行，并会**按当前地图视野优先**返回结果（先把地图移到目标城市再搜，准确度更高）。

说明：搜索基于开放地图数据（OSM），**地标、道路、小区、城市**这类地名效果很好；**连锁门店等 POI**（如"海底捞 XX 店"）覆盖有限——这类需求推荐直接在地图上双击选点。

<details>
<summary>进阶（可选）：接入高德官方搜索</summary>

配置高德 Web 服务 key 后可获得与高德地图 App 完全相同的搜索结果（含全量 POI）。个人开发者 key 有免费额度，是否使用请自行评估：

1. 打开 [高德开放平台](https://console.amap.com/dev/key/app) 注册（手机号即可，免费）
2. 创建应用 → 添加 Key → 服务平台选 **「Web 服务」**
3. 把 key 写入本机配置文件 `~/GeoPort/config.json`：

```json
{ "amap_key": "你的key" }
```

4. 重启 GeoPort CN 即生效（搜索候选面板会标注「高德地图搜索结果」）

> key 只保存在你自己的电脑上，仅用于搜索时请求高德官方接口。
> 未配置则始终使用免费默认搜索，功能完全不受影响。
</details>

## 🛠️ 故障排查

| 现象 | 原因与解决 |
|---|---|
| 设备下拉是空的 | 手机解锁后点页面「刷新」；换一根**数据线**（有些线只能充电）；换个 USB 口 |
| 连接时弹「开发者模式」 | iOS 16 及以下才需要；**iOS 17+ 不需要**（若在 iOS 17+ 上看到此弹窗请报 issue） |
| 页面打开但地图空白 | 高德瓦片失败会自动降级 OSM；若仍空白，多为代理软件（ClashX 等）拦截了 localhost，把 `localhost` 加入代理绕行列表 |
| 搜地点没结果/不准 | 先把地图移到目标城市再搜（按视野优先）；门店类 POI 覆盖有限，可双击地图选点或输入 `纬度, 经度` |
| 双击 app 后没反应 | 冷启动约 20-30 秒属正常，等浏览器自动弹出；看页面右上角徽章（红=未就绪会自动重连）；仍不行看日志 `~/GeoPort/logs/geoport-cn.log` |
| 页面右上角红色「服务未响应」 | 服务正在启动或已停止：稍候页面会自动重连；超过 1 分钟未恢复，双击 app 重启服务；横幅里可点「查看日志」 |
| 模拟不生效 | 确认已点「连接设备」且手机屏幕解锁；点一次「停止模拟」再重新「模拟定位」 |
| 官方 GeoPort 和本工具冲突 | 两者都用 54321 端口，同时只开一个；本工具被占用时会自动换随机端口（看日志） |

## 🗑️ 卸载

与普通 Mac 应用一致：把 `/Applications` 里的 **GeoPort CN** 拖入废纸篓即可。

用户数据（历史/收藏/日志）保存在 `~/GeoPort/`，**默认保留**——重装或升级时
你的收藏和历史不会丢失。如需彻底清除：

```bash
rm -rf ~/GeoPort
```
